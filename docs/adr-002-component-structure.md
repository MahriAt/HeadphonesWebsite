# ADR-002: Bileşen Yapısı

## Problem

Kod tekrarını azaltmak ve daha sürdürülebilir bir yapı kurmak gerekiyordu.

## Karar

Tekrar kullanılabilir bileşenler oluşturuldu (Button, Card, SSS, Info, Iletişim)
Bileşenler modüler şekilde organize edildi
Props ile dinamik yapı sağlandı

## Sonuç

Kod daha okunabilir hale geldi
Yeniden kullanım arttı
Geliştirme süreci hızlandı
